# Personal Developer Portfolio

A modern, responsive personal portfolio website showcasing my skills, projects, education, and development journey.

## About Me

I am a Computer Science and Engineering student passionate about software development, programming, and emerging technologies.

## Features

- Modern and responsive design
- Dark and light mode
- About Me section
- Technical skills showcase
- Project portfolio
- Education and experience
- Contact and social media links

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Lucide Icons
- Google Fonts

## Projects Featured

- Spam Message Detection
- Student Score Prediction
- AI Study Assistant
- Student Performance Predictor

## Run Locally

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
